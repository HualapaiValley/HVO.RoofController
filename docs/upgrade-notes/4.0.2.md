No configuration, account or API changes are required. This patch fixes kiosk text rendering at startup and restores
the Blazor framework assets needed by the web UI after sign-in (#102).

Upgrade an installer-managed controller or Linux test rig with `sudo hvo-roof-install upgrade`, while idle. For a
manually managed deployment, use this release's digest-pinned controller image and kiosk program, following
[Deployment](https://github.com/HualapaiValley/HVO.RoofController/blob/main/docs/deployment.md) and [Kiosk](https://github.com/HualapaiValley/HVO.RoofController/blob/main/docs/kiosk.md). Keep the existing identity store, settings and device key.
