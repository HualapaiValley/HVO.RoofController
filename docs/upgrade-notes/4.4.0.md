Upgrade a controller or emulated rig running 4.3.0 while the roof is idle, with `sudo hvo-roof-install upgrade`.
Upgrade separately installed per-user CLI and Mac clients as their user, without sudo. Keep the pre-upgrade backup
or VM snapshot and the installer's previous-version assets for rollback. No identity-store or settings schema change:
a rollback to 4.3.0 still reads the stores.

**The Alpaca server is not in the image yet.** 4.4.0 ships the ASCOM Alpaca server as a program built from source
([docs/alpaca.md](../alpaca.md)); running it in the controller's container comes later (#229). Every Alpaca command
setting is off by default: `RoofController:Alpaca:AllowCommands` stays `Off`, so no Alpaca client can close or open the
roof until someone with the local credential changes it.

**Check the `RoofSafety` settings before upgrading.** A key under `RoofSafety` that no setting has, or a value that is
not of its type, now stops the controller at start rather than being ignored. A parked telescope alone now reads
Unknown ("No required weather source configured") until a required weather source is set.
