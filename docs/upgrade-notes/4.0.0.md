4.0.0 is the first release, so there is no earlier release to upgrade from.

A controller deployed from a checkout before 4.0.0 moves to it as follows:

- Read the BREAKING changes in the CHANGELOG first: every protected endpoint needs an API key or a person's session,
  commands are POST only, the API is HTTPS on port 8443 by default, and the web UI is on port 8088.
- The production settings now read the documented wiring (IN1 and IN2 normally open, IN3 closed while the drive is
  healthy, IN4 at speed). A deployment that overrides them keeps its own values. Either way, run the commissioning
  checks (docs/commissioning.md) before relying on the roof.
- The camera's Blue Iris credential now comes from `BlueIris:UserName` and `BlueIris:Password`, and the one that was in
  the code must be rotated.
- With the roof closed and idle, run the installer on the Pi. It adopts a controller that the deploy script runs. Move a
  controller that Docker Compose made to the deploy script first (docs/deployment.md, "Moving between Compose and the
  deploy script").
- A controller from before API keys cannot answer the deploy script's verified Stop. Deploy over it once by hand
  (docs/deployment.md, "First deploy over an older controller"), then run the installer.
