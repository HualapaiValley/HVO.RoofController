Upgrade an installer-managed controller or emulated rig while idle with `sudo hvo-roof-install upgrade`.
Upgrade the separately installed per-user CLI or Mac app as that user, without sudo. Upgrade both the
controller and clients to receive the detailed-health and version-display fixes.

No configuration, account, enrollment or identity-store schema changes are required. Keep the installation
record, identity store, settings, certificates and device keys. Existing native Linux authentication and
kiosk PIN permissions remain unchanged. Preserve the complete pre-upgrade backup or VM snapshot and the
installer's previous-version assets for rollback.

Local Linux authorization now permits detailed CLI health and the terminal System page through the existing
read scope. Find the running kiosk or desktop build in About, the terminal build in System (F4), and the web
build in System or the footer. Local versions remain available when controller reads fail. Controller metadata
is labelled separately; the PIN kiosk directs administrators to CLI or web System for the controller version.
