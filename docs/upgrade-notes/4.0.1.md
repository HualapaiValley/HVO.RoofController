no setting, API or file.

as yourself, without `sudo`, for `hvo-roof`, the Mac app or a rig on a Mac. The controller's 4.0.0 is kept as
`roof-controller-previous`, so `hvo-roof-install rollback` (with `sudo` where the upgrade had it) returns to it.
